# DictLite

DictLite 是一款面向 Windows 的中英词典，支持多词典查询、全局快捷查词、收藏与历史记录，以及 MDX 词库转换。

## 功能介绍

### 查词与阅读

- 支持词头精确、前缀、包含匹配和释义反查，也可使用简短中文查询。
- 按词典来源切换释义，同一词典中的同形词释义合并展示和复制。
- 支持收藏、复制释义、文字例句和 Windows 本地系统语音朗读；缺少相应语音时会提示。
- 收藏与历史记录自动保存，重启后保留。
- 按 `Ctrl+K` 定位搜索框，方向键选择候选词，回车查词，`Esc` 收起建议。

### 全局快捷查词

在其他程序中选中文字，按住 `Ctrl` 连按两次 `C`，或连续按两次 `Ctrl+C`，即可在鼠标旁查看简易释义，并进入主窗口查看完整内容。两次复制间隔不超过 650 毫秒，复制内容不超过 256 字，且来源程序需支持普通复制。

快捷窗口支持置顶。未置顶时，切换到其他窗口会自动关闭；置顶后保持显示，也可通过 `Esc` 或关闭按钮关闭。新建快捷窗口默认不置顶。

快捷查词在主窗口隐藏到托盘时仍可使用。设置中的“Ctrl+C+C 快速查词”默认开启，开关即时生效。未复制到新内容时不会查询旧剪贴板，长按 `C` 不会重复触发；正常复制操作不受影响，程序不会主动改写剪贴板。

### 词典与设置管理

- 导入 SQLite 词库时校验格式，并拒绝重复导入相同身份的词库。
- 支持词典启用与停用、显示名称、排序及各词典的例句显示偏好。
- 支持 JSON 设置导入与导出；导出内容仅包含配置，不包含词库、收藏或历史记录。
- 支持 Windows 开机启动、托盘和关闭到托盘。隐藏到托盘后可延迟释放界面资源，再次打开时重建。

### MDX 词库转换

在词典管理中选择 MDX 文件，完成转换、检查结果后导入。转换结果保存文字正文和检索索引，日常查询无需保留原 MDX/MDD。转换支持进度显示、取消、媒体清理和转换报告，默认拒绝覆盖已有输出。

也可使用独立转换器：

```powershell
.\dictlite-convert.exe convert --input "D:\词库\dictionary.mdx" --output "dictionary.sqlite" --report "conversion-report.json" --task-id "conversion-001"
```

`auto` 模式可识别已验证的“简明英汉字典增强版”模板，提取词性、翻译及原有读音文字；无法可靠提取的条目保留完整文字正文。其他词典采用通用文字转换，原词库音标按原文保存。

转换报告列出结构化词条、文字回退、跳过记录和字符问题。`needs_review` 表示存在需要检查的内容缺口。图片扫描正文、加密或不受读取库支持的词库可能无法完整转换；去除媒体也不保证转换结果比压缩后的 MDX 更小。

### 启动与使用

Windows 需要安装 WebView2 Runtime。将便携程序放在可写位置，双击 `dictlite.exe` 启动。首次运行会自动初始化设置、词库目录和个人数据；没有预装词库时，可进入词典管理导入。

迁移时请移动整个便携目录，以保留词库、设置、收藏和历史记录。关闭窗口默认进入托盘，使用设置页或托盘菜单中的“退出”结束程序。

### 当前限制

- 当前以 Windows 为验证平台，尚未实现其他操作系统集成、快捷键自定义、词库覆盖更新、牛津专用模板与自动拼音补全。
- 普通任务栏最小化不会触发界面资源释放，隐藏到托盘才会触发。
- 大型词库的首次转换和完整校验需要时间；查询时不会将整套正文加载到内存。后台内存占用和界面重建时延需在实际环境中测量。

## 开发指引

### 环境要求

- Rust MSVC 工具链。
- Windows C++ Build Tools。
- 可访问的 Cargo 依赖源。
- WebView2 Runtime，用于运行桌面界面。
- Node.js，用于运行前端测试。

项目使用 Rust、Tauri 和 SQLite，前端采用静态 HTML、CSS、JavaScript，无需 npm 开发服务器。

### 构建

在项目根目录使用 PowerShell 执行：

```powershell
.\build.ps1
```

默认构建发布版本并生成便携程序。需要调试版本时执行：

```powershell
.\build.ps1 -DebugBuild
```

### 验证

在项目根目录执行核心与前端测试：

```powershell
cargo test --no-default-features --test core
node --test tests/ui.test.cjs
```

测试使用临时目录，不修改真实词库。
